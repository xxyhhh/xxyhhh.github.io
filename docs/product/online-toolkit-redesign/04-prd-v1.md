# 在线工具集全站重设计与证件照工具 PRD v1

## 1. 版本目标

在保持 GitHub Pages 纯静态部署的前提下，把现有首页和 13 个工具入口统一到 Terminal Slate 视觉系统，增加全站中英文切换，并新增浏览器本地证件照制作工具。

## 2. 功能范围

### 2.1 全站框架

- 建立共享设计令牌、顶部导航、页脚、按钮、表单、卡片、状态和响应式样式。
- 所有页面右上角显示 `中 / EN`；首次使用浏览器语言，后续仅保存语言代码。
- 所有内页使用 `<` 返回首页。
- 首页支持搜索与分类筛选；无结果时显示可恢复空状态。
- “关于与隐私”说明本地处理边界、浏览器缓存和第三方依赖。

### 2.2 工具状态

- M3U8/HLS 继续显示“维护中”，卡片不可点击且无有效链接。
- 可用工具保持现有输入、转换、复制、下载和预览能力。
- 正则语法速查默认展开。
- 二维码默认前景黑色、背景白色，视觉不使用蓝紫主题。

### 2.3 证件照制作

- 支持 JPG、PNG、WebP；前端校验类型、体积和图片解码结果。
- 提供一寸、二寸、小一寸、小二寸及自定义像素/毫米尺寸；输出 DPI 默认 300。
- 支持移动、缩放、旋转、九宫格、头顶线/眼睛线/下巴线辅助构图。
- 用户可不抠图直接裁剪原背景并下载。
- 点击“智能抠图”后才加载浏览器端人像分割模型，并显示下载、初始化和推理进度。
- 支持白、蓝、红、黑和自定义纯色背景；实时预览。
- 支持 JPG/PNG 导出及质量控制；下载前展示尺寸和预计文件信息。
- 替换、清空或离开页面时释放所有用户图片临时资源；用户内容不进入网络或持久化存储。

## 3. 国际化

- 中文为翻译回退语言；英文覆盖导航、标题、说明、按钮、占位符、状态、错误和帮助。
- 语言切换不刷新页面、不丢失输入；同步设置 `<html lang>`、页面标题和无障碍标签。
- 工具名可保留 JSON、JWT、UUID、Cron、Base64 等行业术语。

## 4. 页面与路由

| 路径 | 页面/用途 |
|---|---|
| `/` | 工具首页 |
| `/about.html` | 关于与隐私 |
| `/tools/id-photo/` | 新增证件照制作 |
| `/tools/*/` | 现有工具统一外壳与各自工作区 |
| `/tools/m3u8player/` | 保留文件但首页不提供入口，页面显示维护说明 |

## 5. 非功能要求

- 常见 360px 手机宽度无页面级横向滚动。
- 核心 UI 不依赖运行时 Tailwind CDN、Google Fonts 或远程图标字体。
- 键盘可访问：焦点清晰、按钮语义正确、禁用态不可触发。
- 对用户图片不发起上传请求；语言代码之外不写入持久化存储。
- 图片处理所需模型可按 HTTP 缓存，不包含用户图片或推理结果。
- 复用现有依赖，新增高体积依赖前必须有明确收益和体积评估。

## 6. 验收标准

1. 首页中英文内容完整，切换后刷新仍保持语言；输入类工具切换语言不丢失内容。
2. 所有可用工具可从首页进入，M3U8 无法从卡片进入。
3. 全站无蓝紫主色或蓝紫渐变；组件遵循 Terminal Slate 令牌。
4. 二维码默认黑/白；正则速查默认展开；所有返回入口显示 `<`。
5. 证件照可完成选择图片、裁剪、可选抠图、四色换底、预览、导出与清空。
6. 未点击智能抠图时无模型请求；清空或离开后用户图片不可恢复。
7. 模型失败或设备不支持时，可继续使用手动裁剪和原背景导出。
8. 自动化测试覆盖语言、维护禁用、关键默认值、资源清理和主要转换逻辑；构建/测试全部通过。

## 7. 实施顺序

1. 共享设计令牌、页面外壳和国际化基础设施；
2. 首页、关于页、维护页和工具卡片；
3. 现有工具内页逐一迁移并做功能回归；
4. 证件照裁剪与本地资源生命周期；
5. 人像分割、背景合成、导出和降级；
6. 全站响应式、无障碍、自动化测试与发布验收。

## 8. 技术阶段待决策

- 人像分割运行时与模型的选型、许可、体积和托管方式；
- 现有页面采用共享 JS 注入外壳还是逐页静态标记；
- 图片裁剪复用现有 CropperJS 还是抽取统一裁剪核心；
- 字体采用系统字体栈还是随站点托管开放字体子集。
