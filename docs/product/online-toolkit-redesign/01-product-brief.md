# 在线工具集视觉重设计与证件照工具：项目简报

## 项目摘要

为需要快速处理图片、文本、编码和开发数据的普通用户与开发者，提供一套视觉一致、响应式、无需登录且以本地处理为主的在线工具；本期统一重设计现有全部页面，并新增纯前端证件照制作工具。

## 背景

现有网站可在 GitHub Pages 上直接运行，包含图像、编码生成和音视频等工具。当前主要问题是页面视觉风格不统一、部分第三方工具页面年代感明显、首页功能描述不足、移动端体验不一致，以及缺少高价值的证件照处理能力。

## 目标用户

- 需要临时处理图片、文本、时间、编码数据的普通用户；
- 需要正则、JWT、Cron、Base64 等轻量工具的开发者；
- 希望照片不上传服务器的证件照制作用户。

## 问题陈述

用户需要无需安装、无需登录且尽量保护隐私的轻量工具，但现有页面的一致性、信息表达和移动端体验削弱了可信度与使用效率；证件照用户还缺少本地完成裁剪、尺寸调整和换底色的路径。

## 项目目标

1. 统一首页与全部工具内页的视觉语言、导航、排版、表单、按钮、反馈和响应式布局；
2. 保持现有工具的核心功能与入口关系不退化；
3. 新增独立证件照制作工具，在浏览器本地完成裁剪、换底与下载；
4. 清楚表达维护状态、隐私边界、错误和降级状态。

## 成功指标

- 全部页面使用一致的设计令牌和导航模式；
- 常见手机宽度下不出现页面级横向溢出；
- 现有工具的核心操作仍能完成；
- 维护状态工具没有可访问入口；
- 用户照片不写入网络、Cookie、localStorage、sessionStorage 或 IndexedDB，刷新后无法恢复；
- 证件照用户可完成裁剪、常见尺寸选择、白/蓝/红/黑换底、预览和下载；
- 模型加载、分割失败和设备性能不足均有明确反馈与可用降级路径。

## 本期范围

- 首页及所有现有工具内页的统一重设计；
- 导航、卡片、表单、按钮、状态、帮助说明及响应式规则；
- 独立证件照制作工具；
- 证件照尺寸裁剪、常用尺寸预设、自定义尺寸、白/蓝/红/黑背景、预览与下载；
- 图片处理隐私说明及内存资源释放；
- M3U8/HLS 卡片继续保持维护中且不可访问。

## 非目标

- 账号、登录或用户资料；
- 云端图片上传、存储或服务端处理；
- 付费功能；
- 本期恢复或替换腾讯 TCPlayer；
- 将证件照成品自动保存到浏览器持久化存储。

## 约束

- 保持 GitHub Pages 纯静态部署；
- 桌面和手机浏览器均可使用；
- 人像分割模型按需加载，公共模型文件允许浏览器正常缓存；
- 用户照片仅存在于页面内存，替换、清空、刷新或关闭页面时释放；
- 成品只在用户主动下载后保存到本机；
- 现有页面功能不因视觉重构而发生无关变化。

## 假设

- 访问者无需登录即可使用全部可用工具；
- 主流现代浏览器支持 Canvas、Blob、File API 和所选人像分割运行时；
- 低性能设备可接受较慢的首次分割，但必须允许用户取消或退回手动裁剪。

## 未决问题

- 目标视觉方向与品牌色；
- 首期证件照尺寸预设清单；
- 人像分割方案、模型大小和浏览器兼容基线；
- 全部内页统一到何种布局层级，同时保留各工具的最佳工作区结构。
