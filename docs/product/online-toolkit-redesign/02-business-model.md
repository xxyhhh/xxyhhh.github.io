# 在线工具集视觉重设计与证件照工具：业务模型

## 角色卡

| 角色 | 目标 | 核心任务 |
|---|---|---|
| 中文访客 | 用中文快速完成一次工具操作 | 搜索、筛选、进入工具、输入、复制或下载结果 |
| 海外访客 | 用英文完成与中文用户同等的工具操作 | 切换英文、使用工具、理解提示和错误 |
| 证件照用户 | 不上传照片，在本机得到合规尺寸和背景的证件照 | 选图、裁剪、抠图、换底、预览、下载、清空 |
| 维护人员 | 准确控制工具可用状态并更新双语文案 | 配置可用/维护状态、补充翻译、发布静态站点 |

## 用户任务清单

- T-001：选择中文或英文，并在后续页面保持一致；
- T-002：从首页搜索或按类别筛选工具；
- T-003：进入可用工具，完成输入到结果的核心操作；
- T-004：识别维护中的工具且无法误入；
- T-005：选择本地照片并调整证件照尺寸和构图；
- T-006：主动启动智能抠图并处理模型加载状态；
- T-007：选择背景色、预览并下载证件照；
- T-008：清空照片和全部临时处理资源。

## 主流程

### 全站工具流程

进入首页 → 根据浏览器语言或已保存偏好显示语言 → 用户可切换语言 → 搜索/筛选 → 选择可用工具 → 完成操作 → 复制或下载结果。

### 证件照流程

选择照片 → 校验格式和大小 → 解码预览 → 选择尺寸 → 调整人物位置与裁剪 → 点击“智能抠图” → 按需加载模型 → 人像分割 → 选择白/蓝/红/黑或自定义背景 → 预览 → 下载 → 主动释放本次导出临时资源。

## 分支与异常流程

- 文件格式错误或超过限制：拒绝加载，显示双语错误，保持未选择状态；
- 图片解码失败：释放已创建 URL，回到未选择状态；
- 用户只需尺寸调整：不加载模型，可直接裁剪和下载原背景版本；
- 模型加载失败：保留照片和裁剪状态，允许重试或跳过抠图；
- 人像分割失败：保留原图，不生成伪成功结果，允许调整构图后重试；
- 设备内存不足：停止高成本处理，释放中间缓冲并建议降低分辨率；
- 下载失败：保留最终预览，允许重新下载；
- 用户替换照片或清空：释放旧 Object URL、Canvas、Blob 和模型输入引用；
- 翻译键缺失：回退中文，不显示裸键名；
- 维护工具：展示状态，不输出可导航链接。

## 业务规则

| ID | 规则 |
|---|---|
| BR-001 | 全部工具免登录使用，可用功能不得依赖账号状态。 |
| BR-002 | 全站右上角提供 `中 / EN`，所有可见文案、提示、错误和帮助均参与切换。 |
| BR-003 | 首次访问优先使用已保存语言，否则依据浏览器语言；只持久化 `zh-CN` 或 `en`。 |
| BR-004 | 切换语言不得清空当前工具输入或处理状态；缺失翻译回退中文。 |
| BR-005 | 用户照片不得写入网络请求、Cookie、localStorage、sessionStorage 或 IndexedDB。 |
| BR-006 | 人像模型只有在用户点击“智能抠图”后才加载；公共模型文件可以使用浏览器 HTTP 缓存。 |
| BR-007 | 更换、清空、刷新或关闭页面时，页面不得保留可恢复的用户照片。 |
| BR-008 | 成品只在用户主动下载后保存到本机。 |
| BR-009 | M3U8/HLS 工具保持维护中，任何语言下均无可访问入口。 |
| BR-010 | 现有工具核心输入、转换、复制、预览和下载能力不得因视觉重构退化。 |

## 状态转换

| 当前状态 | 操作者/事件 | 前置条件 | 下一状态 |
|---|---|---|---|
| 未选择 | 用户选择文件 | 格式、大小有效 | 已选择 |
| 已选择 | 图片解码成功 | 浏览器可解码 | 已裁剪（初始构图） |
| 已裁剪 | 用户调整尺寸/构图 | 图片可用 | 已裁剪 |
| 已裁剪 | 用户点击智能抠图 | 浏览器支持运行环境 | 模型加载中 |
| 模型加载中 | 加载和推理成功 | 模型资源可访问 | 已抠图 |
| 模型加载中 | 加载或推理失败 | — | 处理失败（可重试） |
| 处理失败 | 用户重试 | 图片仍可用 | 模型加载中 |
| 已抠图 | 用户选择背景 | 分割蒙版可用 | 已换底 |
| 已裁剪/已换底 | 用户下载 | 可生成 Blob | 已下载 |
| 任意照片状态 | 用户清空/替换 | — | 未选择或新照片已选择 |

## 权限矩阵

| 操作 | 访客 | 维护人员 |
|---|---:|---:|
| 读取页面与工具说明 | 是 | 是 |
| 使用可用工具 | 是 | 是 |
| 切换并保存语言代码 | 是 | 是 |
| 读取用户本地照片 | 仅在用户主动选择后 | 同访客 |
| 上传或持久化用户照片 | 否 | 否 |
| 修改工具状态、翻译和页面代码 | 否 | 通过仓库发布流程 |

## 通知与反馈事件

- 语言切换即时更新；
- 文件校验、图片解码、模型加载、分割、导出均有就地状态；
- 成功下载、清空完成使用轻量反馈；
- 维护工具使用静态徽标和禁用入口，不弹出误导性错误；
- 错误反馈提供原因、可恢复动作和隐私状态。

## 假设与未决问题

- 假设语言偏好可以保存在 localStorage，因为它不包含用户内容；
- 待原型阶段确认全站导航、工具工作区和语言切换位置；
- 待技术阶段确定人像分割模型、运行时、兼容范围和尺寸预设数据。
