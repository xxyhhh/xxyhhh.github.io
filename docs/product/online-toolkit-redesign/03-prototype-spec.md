## 视觉规范

- 背景采用石墨黑 `#121317`，禁止蓝紫、靛紫渐变、玻璃拟态和霓虹光晕。
- 主操作色为森林绿 `#2D6A4F`，辅助色为鼠尾草绿 `#84A98C`。
- 警告使用工业橙 `#D97706`，错误使用红色 `#EF4444`。
- 界面字体优先系统无衬线字体；代码和数据区域使用等宽字体。线上实现不得为基本显示强依赖 Google Fonts。
- 卡片与控件使用 4–8px 小圆角、实色分层和 1px 边框；可点击卡片不做漂浮位移动画。
- 桌面最大内容宽度约 1280–1440px；工具页采用 50/50 或 30/70 工作区；移动端单列并使用输入/结果切换。

## 全局结构

- 顶部：站点名、本地处理状态、全部工具、关于与隐私、`中 / EN`、GitHub。
- 无账号体系，不显示用户头像或登录入口。
- 内页提供字符形式 `<` 返回入口，不使用箭头图标字体。
- 首页提供搜索、分类筛选、工具卡片、维护禁用态和隐私架构摘要。
- 页脚提供隐私、源码、许可证和维护状态入口。

## 交互与状态

- 语言切换覆盖全部可见文案，保存的只有语言代码；切换不清空当前输入。
- M3U8/HLS 首页卡片显示“维护中”，无链接、不可聚焦为可执行入口。
- 证件照按“上传 → 尺寸裁剪 → 智能抠图 → 换底导出”推进；不点击智能抠图就不加载模型。
- 用户图片只存在内存；替换、清空、卸载页面时释放 Object URL、Canvas 和 Blob 引用。
- 模型加载、推理失败、内存不足和不支持 WebAssembly 时保留可恢复路径。

## 原型偏差与实施修正

- Stitch HTML 仅作视觉参考，不直接作为生产代码；其中 Tailwind CDN、Google Fonts 和 Material Symbols 外链将被移除或替代。
- 英文首页仍含中文头部且错误使用 `lang="zh-CN"`，生产实现按当前语言同步更新 `<html lang>` 与全部文案。
- 原型中的头像、虚构版本/性能指标、无实际意义的导航入口不进入生产站。
- 未单独生成的英文内页和移动内页按同一设计系统、真实内容和响应式规则派生。
- 原型中的演示交互必须接入现有工具逻辑，不以静态假按钮替代。

## 阶段结论

视觉方向和核心任务路径通过，可以作为实现基线；上述偏差均属于实现校正项，不要求 Stitch 返工。
