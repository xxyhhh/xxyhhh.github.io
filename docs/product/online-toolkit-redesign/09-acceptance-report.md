# 在线工具集视觉重设计与证件照工具：验收报告

验收日期：2026-09-15  
发布分支：`gh-pages`

## 验收结论

本轮实现通过验收。用户已确认人像抠图精修效果可接受，并同意进入下一阶段。

## 已交付范围

- 全站采用 Terminal Slate 深色石墨与绿色视觉体系，移除蓝紫色主视觉。
- 全站公共外壳提供 `中 / EN` 切换和 `<` 返回入口。
- 首页提供搜索、分类、隐私说明及工具状态展示。
- M3U8 播放器标记为维护中并禁用访问。
- 二维码默认黑色前景、白色背景；正则速查默认展开。
- 图片裁剪提供真实裁剪结果预览：小图不放大，大图等比缩小。
- 证件照支持常用尺寸、人物缩放、智能抠图、蒙版精修、四色背景与 PNG 下载。
- 图片与中间结果仅驻留当前浏览器页面内存；替换、清空或关闭页面时释放。
- 人像模型按需加载并允许浏览器正常缓存，用户照片不上传。

## 验证记录

- 命令：`node --test tests`
- 结果：45 项通过，0 项失败。
- 差异检查：`git diff --check` 通过。
- 用户线上验收：抠图精修效果确认无问题。

## 已知限制与后续迭代

- 部分历史工具的正文尚未逐项完成英文翻译，公共外壳已支持中英文。
- 证件照暂未提供自定义尺寸、拖动定位、旋转、JPG 质量与手动擦除/恢复画笔。
- 轻量浏览器人像模型在复杂遮挡、多人或极细发丝场景仍可能出现误差。

以上项目不阻断本轮验收，进入后续独立迭代管理。
