# 首页工具状态与描述优化设计

## 目标

在首页准确表达 M3U8/HLS 播放器当前不可用的状态，并补充图片工具集的实际功能说明。保持现有纯静态卡片渲染、搜索和分类筛选行为。

## M3U8/HLS 播放器维护状态

- 工具数据增加 `status: 'maintenance'`，以数据驱动方式表达不可用状态；
- 卡片右上角显示橙色“维护中”徽标；
- 原“进入工具”链接替换为灰色禁用按钮“暂不可用”；
- 维护状态不渲染 `<a href>`，确保鼠标和键盘都无法进入播放器页；
- 卡片增加 `aria-disabled="true"`，禁用按钮增加 `disabled`，提供明确语义；
- 卡片仍参与“音视频”分类和关键词搜索，便于用户知道该工具只是暂时维护，而非被删除。

## 图片工具集描述

首页描述改为：

> 本地旋转、水平翻转，并支持 JPG、PNG、WebP 格式转换与下载（最大 10MB）

文案只列出现有实现已经支持的功能，不把尚未实现的证件照功能写入卡片。

## 样式

- 卡片顶部标签容器占满可用宽度；
- “维护中”徽标使用低饱和橙色，放在分类标签右侧并靠右；
- 禁用按钮降低饱和度和对比度，使用 `not-allowed` 光标，不响应悬停位移；
- 正常工具卡片的现有样式与行为不变。

## 验证

1. 静态测试确认 M3U8 数据包含维护状态；
2. 渲染实现对维护状态输出徽标、`aria-disabled` 和无链接的禁用按钮；
3. 图片工具集描述与实际的旋转、翻转、格式转换和 10MB 限制一致；
4. 普通工具仍输出可访问的“进入工具”链接；
5. 浏览器检查桌面及窄屏下徽标位置、禁用按钮和卡片排版。

## 非目标

- 不删除或修改 M3U8 播放器页面；
- 不申请或替换腾讯云 License；
- 不在本次变更中实现证件照处理。证件照尺寸与换背景功能作为后续独立设计处理。
