# 全站完整中英文本地化设计

日期：2026-09-15  
状态：待用户书面规格确认

## 目标

在不改变工具 URL、核心功能和本地隐私边界的前提下，使用户点击右上角 `中 / EN` 后，当前页面的全部用户可见界面文案立即切换为中文或英文。刷新、返回首页及进入其他工具后继续使用已选择的语言。

## 已确认方案

采用单 URL、页面内字典切换。每个工具维护自身的中英文字典，并复用 `assets/js/i18n.js` 的语言状态和页面更新机制。不创建 `/en/` 页面副本，不依赖浏览器自动翻译或在线翻译服务。

## 页面范围

本轮覆盖以下生产页面和工具：

1. 首页与关于/隐私页
2. 时间戳/时区转换器
3. 文本整理工具
4. Base64/URL/UTF-8 编解码
5. JSON/CSV/YAML 互转
6. UUID/随机密码/Nonce 生成
7. Cron 可视化
8. JWT 解码与校验
9. 正则测试台
10. 二维码生成器
11. 图片裁剪
12. 图片工具集及其内嵌页面
13. 证件照制作
14. M3U8/HLS 维护状态页

开发模板、第三方库、许可证、README 和已停用的旧 M3U8 实现不属于用户界面，不进行翻译。

## 文案覆盖规则

- 静态内容：标题、分组、标签、按钮、说明、隐私提示、维护提示、占位符及无障碍标签。
- 动态内容：复制成功、校验结果、解析失败、输入校验、加载中、处理成功、处理失败及空状态。
- 浏览器原生文件选择按钮受浏览器语言控制，不伪造自定义翻译。
- `JSON`、`CSV`、`YAML`、`JWT`、`UUID`、`Nonce`、`Cron`、`Unix`、`ISO`、`Base64`、`URL`、`UTF-8`、`PNG`、`JPG`、`WebP` 和 `M3U8/HLS` 等技术标识保留英文。
- 日期和时间结果使用当前语言对应的 locale；机器格式值不翻译。
- 用户输入、生成数据和错误对象原文不进入翻译字典，界面前缀与解释文字翻译。

## 实现结构

### 公共国际化层

扩展 `assets/js/i18n.js`，继续提供语言读取、切换、注册字典和页面翻译。补充属性翻译与格式化辅助能力时保持向后兼容，不引入框架或远程依赖。

### 工具页面层

每个工具注册命名空间化键名，例如 `cron.copy`、`jwt.invalidFormat`、`cropper.previewHint`。静态节点使用 `data-i18n` 系列属性；动态提示调用 `ToolkitI18n.translate()`，禁止根据按钮当前中文文本反推状态。

### 内嵌图片工具

外层页面把语言同步给同源 iframe。内嵌图片工具使用同一语言代码和翻译约定，切换后无需刷新 iframe。

## 状态与数据流

1. 页面加载时读取 `toolkit-language`；未设置时根据浏览器语言选择中文或英文。
2. 页面注册本页字典并执行首次翻译。
3. 用户点击语言按钮后更新唯一语言代码，触发 `toolkit:languagechange`。
4. 静态节点立即更新；当前动态状态依据状态变量重新渲染。
5. iframe 页面接收同源语言同步并更新自身界面。

语言切换不清空表单、不重置图片、不重新运行转换、不重新下载模型。

## 异常与降级

- 缺少英文键时回退中文并由自动测试报告缺口，不显示裸键名。
- `localStorage` 不可用时，本页面切换仍生效，但刷新后回到浏览器默认语言。
- 剪贴板、图片模型等能力失败时，错误提示使用当前语言，原功能降级策略保持不变。
- 第三方运行时错误只显示经过整理的中英说明，不直接把不可理解的内部堆栈呈现给用户。

## 验收标准

- 两种语言下，14 个生产入口均可访问且功能不回归。
- 英文模式下不存在遗留的用户界面中文文案；允许用户内容、代码注释和中英语言按钮中的“中”。
- 中文模式下不存在仅英文且应翻译的说明文案；技术标识例外。
- 切换语言不会丢失输入、裁剪状态、证件照图片或转换结果。
- 动态成功、失败和校验提示均随当前语言生成。
- iframe 图片工具与父页面语言一致。
- 自动化测试、脚本语法检查与 `git diff --check` 全部通过后才发布。
