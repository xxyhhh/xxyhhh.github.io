# 工具页面细节优化设计

## 目标

对静态工具站的二维码生成器、正则测试台和全站工具页返回入口做小范围优化，并明确现有 M3U8/HLS 播放器的腾讯云依赖。保持纯静态部署方式，不引入构建流程或后端服务。

## 已确认需求

1. 二维码生成器不再使用蓝色、靛色或紫色渐变，采用低饱和墨绿方案。
2. 二维码“外观设置”的前景色默认值为黑色 `#000000`，背景色默认值为白色 `#FFFFFF`。
3. 正则测试台的“常用正则语法速查”首次进入页面时默认展开，用户仍可手动收起。
4. 所有工具页面的返回入口统一显示为 `< 返回首页`，HTML 源码使用 `&lt;` 表达小于号。
5. 本次不替换或改造 M3U8/HLS 播放器，仅说明其实现方式和腾讯云配置要求。

## 设计

### 二维码生成器

保留现有页面结构、输入类型、二维码生成逻辑和下载逻辑，只调整视觉样式：

- 页面背景使用浅灰绿或接近白色的中性底色；
- 标题区使用沉稳墨绿纯色或同色系低对比渐变；
- 主操作按钮使用墨绿，次要按钮保持中性灰；
- 不使用蓝色、靛色、紫色及其渐变作为页面主视觉；
- 保持颜色输入框的 `value` 分别为 `#000000` 和 `#FFFFFF`，生成函数继续读取这两个控件的当前值。

### 正则速查

为现有 `<details class="cheat">` 增加布尔属性 `open`。不增加持久化状态，因此每次重新载入页面时恢复为展开状态。

### 返回入口

修改 `tools/` 下模板及全部工具入口页中 `.back` 链接的可见文本，将 `← 返回首页` 统一替换为 `&lt; 返回首页`。链接地址、样式类和导航行为保持不变。

### M3U8/HLS 播放器说明

当前页面通过 CDN 加载腾讯云 TCPlayer 5.1.0，并将用户输入的媒体 URL 传给 `TCPlayer`/`player.src()`。播放器配置中包含一个腾讯云 Web 播放器 `licenseUrl`。

- 播放公开可访问的 M3U8 地址本身不要求开通腾讯云点播；
- 继续使用 TCPlayer SDK 需要有效的 Web 端播放器 License，并为实际域名配置授权；
- 腾讯云 Web 端基础版 License 可免费申请但有有效期，需要在腾讯云的 License 管理中维护；
- 媒体源仍必须允许 HTTPS 访问、跨域请求和分片加载；源站防盗链、鉴权或 CORS 限制可能导致无法播放。

本次不修改播放器代码，也不迁移到 hls.js。

## 验证

使用自动化静态检查验证：

1. 二维码页面不再包含原蓝紫色值，且颜色控件默认值为黑白；
2. 正则速查 `<details>` 包含 `open`；
3. 所有工具页 `.back` 链接均使用 `&lt; 返回首页`，且不存在旧文本；
4. HTML 文件可被解析，关键本地资源路径仍存在；
5. 通过本地静态服务器浏览二维码页、正则页和至少一个其他工具页，检查桌面及窄屏布局。

## 非目标

- 不调整首页主题；
- 不修改二维码生成能力或数据格式；
- 不新增腾讯云服务、账号配置或媒体托管；
- 不发布到 GitHub Pages，除非用户另行明确要求推送或部署。
